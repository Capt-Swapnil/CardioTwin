Closed-Loop Pacemaker Comparison

Identical intrinsic disturbances, initial state and actuator constraints for all methods. Pacing adds captured beats through a ventricular phase reset; it cannot directly slow an intrinsically fast rhythm. This reduced-order plant is downstream of the SA/AV oscillators.

Plant, controller and metric definitions

Plant: φ[k+1] = φ[k] + Δφnative[k]. A threshold crossing emits an intrinsic ventricular beat. A captured unit pulse u[k] = 1 resets φ to zero and emits a paced beat. The phase increments replay the original simulated RR disturbances for every method, including block, AF and PVCs. Pacing can shift subsequent ventricular activation. It does not modify the upstream SA/AV oscillator equations.

Constraints: control sample 50 ms; no delivered pulse within 250 ms of a sensed beat; at least 500 ms between delivered pulses. Natural activation is processed before a simultaneous pacing decision. Fixed pacing attempts a target-period clock pulse and inhibits unsafe attempts; reactive pacing waits until no beat has occurred for one target RR interval. These are simplified comparison laws.

Adaptive MPC: the digital twin supplies an ideal observed ventricular phase. An EWMA updates the intrinsic phase-rate estimate (gain 0.2, initial 1.2 cycles/s); it receives no future disturbance schedule. At every enabled sample, a beam search (width 16) predicts binary pulse sequences over the selected horizon using the current estimate, applies the first action, then repeats. This approximate finite-horizon optimiser carries no global optimality or closed-loop stability guarantee.

Objective: sum over the horizon of Δt[(ŷ/r − 1)² + 0.5 max(age/R − 1, 0)²] + 2Σ(RR/R − 1)² + ρΣu², where r is the target rate, R = 60/r, age is time since the last beat, and ρ is the pulse penalty. The RR cost is applied only when a predicted beat has a preceding beat. The phase-rate estimate is held fixed within each horizon.

Measurements: y = 60/max(last completed RR, time since last beat). Before a completed RR is available, the displayed rate is zero (no estimate). Pre-window simulated beat history initialises all methods identically where available. RMSE = √[∫(y−r)²dt/T]; IAE = ∫|y−r|dt. Left-rectangle integration uses the 50 ms held output.

Settling: time after control enable when rate first enters ±5 bpm and stays there for the entire remaining record, with at least 3 seconds of confirmation. A shorter tail or a later band violation cannot count as settled. Effort is Σu[k]²; each delivered unit pulse counts as one. This is a normalised stimulation measure, not battery energy in joules.

Scope: a simulation experiment with perfect phase sensing and guaranteed unit-pulse capture. It is not a validated pacemaker, AF termination model, learned arrhythmia predictor, or clinical treatment model. Reference: MathWorks: adaptive and time-varying MPC.

Technical Information – Mathematical Model

Coupled Van der Pol Oscillator System

The cardiac conduction model uses two coupled Van der Pol oscillators representing the SA (sinoatrial) and AV (atrioventricular) nodes. The SA oscillator acts as the primary pacemaker, driving the AV oscillator through unidirectional coupling.

State-Space Formulation

SA Node:
dx₁/dt = y₁
dy₁/dt = μ(1 − x₁²) y₁ − ωSA² x₁
AV Node (with coupling):
dx₂/dt = y₂
dy₂/dt = μ(1 − x₂²) y₂ − ωAV² x₂ + k(x₁ − x₂)

Parameters

ωSA = 2π fSASA natural angular frequency
ωAV = 2π fAVAV natural angular frequency
μVan der Pol nonlinearity parameter (controls relaxation oscillation shape)
kUnidirectional coupling strength (SA → AV)

Composite Cardiac Waveform

ECG(t) = atrial templates + ventricular templates + AF baseline

SA upward zero crossings drive atrial events after a 10-second oscillator burn-in. A separate event layer conducts beats with delay 0.12 + 0.06/(1+k) seconds, blocks alternate beats for 2:1 block, and inserts early PVCs with a suppressed following response. At k = 0 there is no conduction or escape rhythm. The AV oscillator trace remains a dynamical proxy; it is not a ventricular activation trace.

AF uses time-modulated atrial drive and seeded irregular ventricular intervals (0.55–1.45)/fSA seconds, without organised P waves. Gaussian templates illustrate P/QRS/T morphology and wider PVCs. All amplitudes are arbitrary units; this is not a validated electrophysiological ECG model. Ventricular rate = 60/mean RR; RR CV = 100 × population SD(RR)/mean RR. Conduction delay averages only visible conducted events, excluding PVCs; AF has no paired atrial events.

Numerical Integration

The system is integrated using the classical fourth-order Runge–Kutta (RK4) method with fixed step size Δt = 0.0005 s.

k₁ = f(tₙ, yₙ)
k₂ = f(tₙ + Δt/2, yₙ + Δt k₁/2)
k₃ = f(tₙ + Δt/2, yₙ + Δt k₂/2)
k₄ = f(tₙ + Δt, yₙ + Δt k₃)
yₙ₊₁ = yₙ + (Δt/6)(k₁ + 2k₂ + 2k₃ + k₄)

Initial state at the start of the 10-second burn-in: x₁ = 0.1, y₁ = 0, x₂ = 0, y₂ = 0. AF substitutes ωSA(t) = ωSA[1 + 0.24 sin(2.7t) + 0.13 sin(7.1t)].
